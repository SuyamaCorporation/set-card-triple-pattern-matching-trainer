# SETカード3組パターンマッチングトレーナー

12枚のカードから4属性（数・色・形・塗り）がすべて同一かすべて異なる3枚組（SET）を見つけるパターン認識トレーニングゲームです。

## 機能
- 数・色・形・塗りの4属性×3値＝81種類のカードデッキを完全再現
- 12枚レイアウトでSETを発見したらカードをクリックして選択
- タイムアタックモードとヒント機能
- 正解・不正解のフィードバックと発見SET数の記録

## 使い方
ブラウザで開き、表示された12枚のカードからSETとなる3枚を選んでクリックします。3枚選択した時点で自動判定され、正解なら新しいカードに入れ替わります。
